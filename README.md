# Drenagem Pluvial 2 — Total Civil

Programa de microdrenagem urbana (chuva IDF, bacias, sarjetas e bocas de lobo, ramais, PVs, rede tronco, linha piezométrica, gerador de rede pela topografia em 3 opções, verificação com correção automática, planta, perfil, seção, 3D, orçamento EMOP/SINAPI/SCO e memorial).

- `index.html` — o programa (arquivo único).
- `.claude/skills/drenagem/CALCULOS.md` — guia dos cálculos, critérios e normas.
- `.claude/skills/drenagem/testes/` — testes automáticos (Playwright).
- `CLAUDE.md` — histórico e regras.

Publicado em https://totalcivil.com.br/drenagem2/ (com login).
